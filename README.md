# Codveda Business Analytics Internship

This repository contains the tasks completed during my Business Analytics Internship at Codveda Technologies.

## Completed Tasks

### Level 1 - Task 1: Understanding Business Analytics
Studied the fundamentals of Business Analytics, including:
- Descriptive Analytics
- Diagnostic Analytics
- Predictive Analytics
- Prescriptive Analytics
- Business metrics and KPIs
- Applications of Business Analytics in different industries

### Level 1 - Task 2: Data Collection and Cleaning
Performed data preprocessing and cleaning using Python and Google Colab.

The task included:
- Loading and inspecting the dataset
- Checking missing values
- Checking duplicate records
- Detecting potential outliers using the IQR method
- Standardization
- Normalization
- Understanding structured and unstructured data

### Level 1 - Task 3: Exploratory Data Analysis
Performed Exploratory Data Analysis (EDA) using Python.

The analysis included:
- Mean, median, mode, and standard deviation
- Histograms
- Scatter plots
- Correlation analysis
- Correlation heatmap
- Linear regression
- R-squared evaluation
- Analysis of patterns and anomalies

### Level 2 - Task 1: Business Intelligence and Reporting
Created an interactive Customer Churn Analysis Dashboard using Microsoft Power BI.

The dashboard includes:
- Total Customers
- Churned Customers
- Churn Rate
- Average Customer Service Calls
- Churn analysis by State
- Churn Rate by International Plan
- Churn Rate by Customer Service Calls
- Average Day Minutes by Churn
- Interactive slicers and filters
- Drill-down functionality
